# 2026-03 정보보안팀 접근 권한 정기 검토 회의록

분기 접근 권한 검토 회의 기록이다. 퇴사자·직무 변경자 계정과 운영 DB 직접 접근 권한을 훑었다.

## 배경

2026-02 내부 감사에서 "퇴사자 계정이 평균 11일간 살아 있다"는 지적을 받았다.
권한 회수가 인사 시스템과 연동되지 않고 팀장 요청 메일에 의존하고 있어서, 요청이 늦으면 계정도 늦게 닫힌다.
운영 DB에 직접 접근할 수 있는 계정이 14개인데 그중 4개는 관리 주체가 바뀐 뒤에도 그대로 남아 있었다.

## 논의한 내용

인사 시스템 연동을 기다릴지, 먼저 수동 절차라도 주기를 줄일지를 두고 의견이 갈렸다.
연동은 인사팀 로드맵상 2026 하반기라 당장 쓸 수 없다는 점에 모두 동의했다.
운영 DB 직접 접근을 아예 닫고 조회 전용 복제본만 열어주는 대안도 검토했지만,
장애 대응 중에는 원본을 봐야 하는 경우가 있어 전면 차단은 무리라고 판단했다.

## 결정 사항

- 퇴사·직무 변경 시 권한 회수 기한을 영업일 3일 이내로 확정한다.
- 운영 DB 직접 접근 계정은 분기마다 재승인한다. 재승인되지 않은 계정은 자동 비활성화한다.
- 담당자가 바뀐 4개 계정은 이번 주 안에 회수한다.

## 결정 근거

인사 시스템 연동은 반년 뒤라 그때까지 감사 지적을 방치할 수 없다.
기한을 3영업일로 잡은 이유는 팀장 부재(연차·출장)를 감안한 현실적인 상한이기 때문이다.
1일로 잡으면 지켜지지 않고, 지켜지지 않는 기준은 없는 기준과 같다.
분기 재승인은 이미 분기 검토 회의를 하고 있으므로 추가 부담이 거의 없다.

## 액션 아이템

- 담당자: 이도윤 / 기한: 2026-03-20 / 운영 DB 직접 접근 계정 4개 회수
- 담당자: 이도윤 / 기한: 2026-03-27 / 분기 재확인 체크리스트 초안 작성
- 담당자: 박서준 / 기한: 2026-04-10 / 인사팀과 연동 일정 재확인

## 영향 범위

운영 DB 접근 권한을 가진 전 조직 실무자가 분기 재확인 대상이 된다.
플랫폼본부 인증팀·결제팀은 장애 대응 계정을 별도로 신청해야 한다.
