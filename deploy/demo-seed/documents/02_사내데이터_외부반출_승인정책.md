# 사내 데이터 외부 반출 승인 정책 v1.2

보안본부가 관리하는 데이터 반출 기준이다. 2026-04-01부터 적용한다.

## 적용 범위

전 조직 임직원과 계약 기간 중인 외부 인력에게 적용된다.
고객 개인정보, 결제 거래 내역, 인증 로그, 소스 코드가 대상이다.
공개 자료로 이미 배포된 문서와 채용 공고처럼 대외 공개를 전제로 만든 자료는 대상이 아니다.

## 정책 내용

반출은 목적과 보관 기간을 함께 적어 신청해야 한다. 목적이 "분석용"처럼 범위를 특정하지 못하는 신청은 반려한다.
개인정보가 포함된 데이터는 가명 처리 후에만 반출할 수 있고, 가명 처리 결과는 신청서에 첨부한다.
반출 매체는 회사가 지정한 저장소만 쓴다. 개인 메일과 개인 클라우드는 매체로 인정하지 않는다.

## 확정된 규정

- 고객 개인정보의 원본(가명 처리 전) 반출은 사유를 불문하고 금지한다.
- 반출 승인은 데이터 소유 조직의 조직장과 정보보안팀의 2인 승인을 받는다.
- 반출 이력은 3년간 보관한다.
- 승인 없이 반출한 사실이 확인되면 접근 권한을 즉시 회수하고 감사 절차를 개시한다.

## 예외와 승인 절차

장애 대응과 규제 기관 제출은 예외로 인정한다.
장애 대응은 선반출 후 24시간 이내 사후 신청을 허용하되, 사후 신청이 없으면 무단 반출로 본다.
규제 기관 제출은 법무팀 검토를 거치고 정보보안팀 승인은 생략한다 — 제출 기한이 법으로 정해져 있어 내부 승인으로 지연시킬 수 없다.

## 시행일과 재검토 시점

2026-04-01 시행한다. 2027-04 정기 재검토한다.
가명 처리 기준이 법령 개정으로 바뀌면 재검토 시점을 앞당긴다.
